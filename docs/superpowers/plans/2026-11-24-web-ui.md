# Web UI v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the server-rendered CiteProof web UI (login, consent, upload, progress, four-tab report with collation sheet, feedback, deletion, sample data, local demo mode) on top of the M1 foundation.

**Architecture:** FastAPI routes under `citeproof.web` render Jinja2 templates and call a `citeproof.services` layer that owns all SQL; HTMX swaps fragments (progress polling, claim sheet, feedback). Files go through a `Storage` protocol with a local backend. Sample data is written into the real result tables so the same pages show sample and real results.

**Tech Stack:** Python 3.12, FastAPI, Jinja2, HTMX 2 (vendored), SQLAlchemy 2 async + psycopg3, Alembic, argon2-cffi, python-multipart, pytest + httpx ASGITransport.

**Spec:** `docs/superpowers/specs/2026-11-24-web-ui-design.md`, with `.stitch/DESIGN.md` (tokens, components, labels §8) and `.stitch/SITE.md` (routes). Visual reference: `.superpowers/brainstorm/4751-1795454244/content/prototype-v1.html` (Hướng A).

## Global Constraints

- UI language Vietnamese; every status, reason, relation, stage, warning label comes from `citeproof/web/labels.py`, which mirrors DESIGN.md §8 verbatim. Templates never hard-code a status label.
- Forbidden anywhere in rendered HTML or Markdown export: `bịa đặt`, `giả mạo`, `không tồn tại`, `gian lận`, `đạo văn`.
- `NOT_FOUND_IN_SEARCHED_SOURCES` uses the hollow badge (`st absent`), `LOOKUP_FAILED` the dashed badge (`st syserr`); red tone only for `CONTRADICTED`, input errors, delete buttons, failed steps.
- Every status badge = glyph + text + tone.
- CSP `default-src 'self'; img-src 'self' data:; style-src 'self'; script-src 'self'; frame-ancestors 'none'; form-action 'self'` on every response: no inline `<script>`, no `style=` attributes, no `on*=` handlers in templates.
- Every state-changing request is POST and CSRF-checked (form field `csrf_token` or header `X-CSRF-Token`).
- Another user's document/run/claim → 404, never 403.
- Never log document text, source text, passwords, session tokens, invite codes, CSRF tokens.
- Jinja2 autoescape on; user strings are never marked safe.
- No numbers that are not counted from data; missing data renders `[chưa có]`.
- `make check` (ruff, ruff format, mypy strict) clean and `CITEPROOF_REQUIRE_DB=1 uv run pytest -q` green at the end of every task.
- Commits: conventional prefix, English subject, body ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Concurrent double submit of "Bắt đầu kiểm tra" / "Kiểm tra lại" on one document → exactly one active run (document row locked). Test in Task 6.
2. Markup in user strings (filename, pasted text, reference strings, feedback comment) → rendered escaped, never executed. Test in Task 6 and Task 11.
3. Session expiry during an HTMX request (progress polling, claim sheet) → `HX-Redirect: /login` header, not a login page swapped into a fragment. Test in Task 5.
4. Vietnamese input in NFD form (macOS filenames, copy-paste) → stored and displayed NFC. Test in Task 6.
5. Long unbroken strings (DOIs, URLs, raw references) at 390 px width → no horizontal page scroll. Checked in Task 14 screenshots; CSS rule in Task 4.

**Interfaces:**

- Produces (`citeproof.services.auth`):

  - `hash_password(password: str) -> str`; `verify_password(password_hash: str, password: str) -> bool` (Argon2id via `argon2.PasswordHasher()` defaults).
  - `async create_user(session, *, email: str, password: str, display_name: str, role: UserRole = UserRole.USER) -> User` — `InputError` codes `EMAIL_TAKEN`, `PASSWORD_TOO_SHORT`, `INVALID_EMAIL` (no `@`).
  - `async create_invite(session, *, created_by: UUID | None, expires_in_days: int | None = 14) -> str` — returns plaintext `secrets.token_urlsafe(12)`; stores `sha256(code).hexdigest()`.
  - `async register_with_invite(session, *, code: str, email: str, password: str, display_name: str) -> User` — `InputError(code="INVITE_INVALID")` for unknown/used/expired; marks invite used in the same transaction (row lock `FOR UPDATE`).
  - `async authenticate(session, settings, *, email: str, password: str, ip: str) -> User` — records a `LoginAttempt` every call; `RateLimitedError` when failures in the last `login_window_minutes` reach `login_max_failures_per_email` for the email or `login_max_failures_per_ip` for the ip (checked before verifying); `AuthError(code="INVALID_CREDENTIALS")` for unknown email or wrong password (same message, still runs a dummy hash for unknown email); deletes attempts older than 1 day.
  - `async create_session(session, settings, *, user_id: UUID) -> str` — returns token `secrets.token_urlsafe(32)`; stores `sha256` hex; `csrf_token = secrets.token_urlsafe(32)`; `expires_at = now + session_ttl_days`.
  - `async load_session(session, settings, token: str) -> tuple[User, WebSession] | None` — `None` if unknown/expired/user deleted; on success slides `expires_at` and `last_seen_at` (at most once per minute).
  - `async delete_session(session, token: str) -> None`.
  - `needs_consent(user: User, settings) -> bool` — `consent_llm_at is None or consent_llm_at < settings.consent_text_updated_at`.
  - `async record_consent(session, user: User) -> None`.
- Produces (`citeproof.cli`): `python -m citeproof.cli create-user --email E --name N [--admin]` (password read with `getpass`, twice), `create-invite [--days N]` (prints code), `seed-sample --email E` (wired in Task 9). Returns exit code 0/1; prints Vietnamese messages; never prints passwords.
